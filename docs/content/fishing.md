# 🎣 낚시 입문

처음 접속할 때 받는 **인챈트 없는 낚싯대 1개**로 시작할 수 있어요.

## 낚시 시작하기

1. 강·호수·바다처럼 물이 충분한 곳을 찾습니다.
2. 낚싯대를 손에 들고 우클릭해 찌를 던집니다.
3. 물방울이 찌에 다가와 입질하면 다시 우클릭합니다.
4. 잡은 물고기는 식량으로 쓰거나 모아두세요.

## 🏆 mcMMO와 함께 성장하기

마루에 설치된 mcMMO에는 **낚시(Fishing)** 스킬이 있어요. 낚시하면서 스킬을 키우고 [mcMMO 성장 가이드](./mcmmo.md)에서 다른 생활 스킬도 확인하세요.

:::note 커스텀 낚시 콘텐츠
낚시용 리소스팩과 확장 콘텐츠를 검토한 이력이 있지만, 현재 서버의 특별 어종·판매 가격·보상 목록은 아직 확정하지 않았습니다.
:::
