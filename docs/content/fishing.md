# 🎣 PyroFishingPro — 마루의 커스텀 낚시

마루에서는 **PyroFishingPro**로 일반 낚시보다 훨씬 다양한 콘텐츠를 즐길 수 있어요. 자체 추가한 **커스텀 물고기 22종**도 포함되어 있습니다.

## 처음 시작하기

1. 처음 접속 때 받은 **인챈트 없는 낚싯대**를 준비합니다.
2. 강·호수·바다에서 찌를 던져 물고기를 낚습니다.
3. `/fish menu`로 낚시 메인 메뉴를 엽니다.
4. `/fish codex`에서 잡을 수 있는 커스텀 물고기를 살펴봅니다.
5. 낚시 레벨을 올리고 미끼·스킬·강화·배달을 차근차근 도전합니다.

:::important
**PyroFishingPro 낚시 레벨과 mcMMO 낚시 레벨은 서로 다릅니다.** PyroFishingPro 레벨은 `/fish stats`에서 확인하세요.
:::

## 🧭 낚시 메뉴 사용법

| 명령어 | 하는 일 |
|---|---|
| `/fish menu` | 낚시 메인 메뉴 |
| `/fish codex` | 커스텀 물고기 도감 |
| `/fish stats` | 낚시 레벨과 통계 |
| `/fish bag` | 물고기 가방 |
| `/fish shop` | 물고기 판매소 |
| `/fish bait` | 미끼 상점/메뉴(활성화 시) |
| `/fish skills` | 스킬 포인트와 능력 |
| `/fish augment` | 낚싯대 강화 장착 |
| `/fish augments` | 강화 목록 |
| `/fish entropy` | 엔트로피 보유량 |
| `/fish deliveries` | 배달 의뢰 |

## 🪱 미끼 사용하는 방법

1. `/fish bait` 또는 `/fish menu`에서 미끼 메뉴를 확인하세요.
2. 미끼가 있다면 설명에 표시된 적용 방식에 따라 **낚싯대에 미끼를 드래그**합니다.
3. 특정 물고기는 해당 미끼가 있어야 잡힐 수 있어요.
4. 미끼 사용 횟수가 남았는지 아이템 설명을 확인하세요.

:::note 마루 커스텀 물고기
마루에 추가한 **22종 물고기의 이름·등급·서식 지역·필요 미끼**는 실제 fish 설정 파일과 대조해야 정확합니다. 도감에서 현재 물고기 목록을 확인하세요. 이 문서에는 이름을 임의로 만들어 넣지 않았습니다. 일부 설치 로그에서 미끼가 0개로 읽힌 이력이 있어 실제 미끼 판매 가능 여부도 확인이 필요합니다.
:::

## 🔮 낚싯대 강화(Augment)

PyroFishingPro 전용 낚싯대 강화 아이템을 **Augment**라고 합니다.

1. `/fish augments`에서 만들 수 있는 강화의 재료를 확인하세요.
2. 일부 강화는 공식 기본 방식대로 **가마솥에 재료를 넣고 낚싯대로 쳐서** 제작합니다.
3. `/fish augment`를 열어 낚싯대와 강화 아이템을 각각 슬롯에 놓습니다.
4. **확인 버튼**을 눌러 강화 효과를 적용합니다.

엔트로피와 강화 재료를 먼저 확인하세요. 가격·확률·필요 레벨은 서버 설정이나 버전에 따라 달라질 수 있습니다.

## 🪙 엔트로피와 성장

커스텀 물고기 관련 활동으로 엔트로피를 획득하여 낚시 콘텐츠 성장에 사용할 수 있습니다. 사용 방법은 게임 내 각 메뉴를 확인해 주세요.
