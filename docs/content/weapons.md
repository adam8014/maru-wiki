# 🔫 커스텀 총기와 CS어택

마루에서는 총기 모델과 전투 방식을 바탕으로 **MaruStrike / CS어택** 콘텐츠를 개발해 왔습니다.

## 어떤 콘텐츠인가요?

- 커스텀 총기 모델과 리소스팩을 사용하는 전투 콘텐츠
- 총기 조작 및 게임 모드를 별도로 개발·조정 중인 시스템
- 일반 마인크래프트 생존 도구와는 다른 전투 경험

## 시작하기 전에

1. [서버 리소스팩](/guide/start/resources)을 적용해 주세요.
2. 운영자가 안내한 입장 방식으로 참가하세요.
3. 참가 전 실제 게임 안에서 조작법을 확인하세요.

:::warning 현재 확인 중
총기 좌클릭 연사 기능과 키 배치 등을 수정·검토한 기록이 있습니다. **최종 동작 확인 전에는 좌클릭 연사가 지원된다고 안내하지 않습니다.** 정확한 조작법과 입장 명령어는 확인되는 대로 반영됩니다.
:::
