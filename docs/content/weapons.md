# 🔫 CS어택 — 마루 커스텀 총기 미니게임

**CS어택**은 마루에서 직접 제작·수정한 총기 전투 미니게임입니다. 커스텀 총기 모델과 전용 게임 화면, 라운드 진행을 활용합니다.

## 참가하는 방법

1. **서버 리소스팩을 적용**합니다. 총기의 외형을 정상적으로 보는 데 필요해요.
2. 채팅에 `/cs어택`을 입력해 게임 메뉴를 엽니다.
3. 게임 내 메뉴에서 참가 가능한 경기를 선택합니다.
4. 경기 중에는 화면에 나타나는 안내를 확인하고 팀과 협력하세요.

## 게임 플레이 흐름

- 게임에 입장하면 경기의 규칙과 장비를 확인합니다.
- 서로 협력하고 상대를 견제하며 미니게임의 목표를 달성합니다.
- 사망·탈락 후 관전 화면이나 경기 결과 메뉴가 표시될 수 있습니다.
- 경기에서 나가려면 `/cs어택 leave`를 사용합니다.

:::warning 조작법 확인
총기 **발사·재장전 키와 좌클릭 연사**는 개발 과정에서 수정한 이력이 있습니다. 최종 버전의 조작키가 확정되기 전에는 정확하지 않은 키 안내를 하지 않습니다.
:::

:::info
최종 패키지 기준에 따라 일부 게임 메뉴와 화면이 개선 중일 수 있습니다. `/cs어택 start force`처럼 경기 강제 시작에 쓰는 운영 명령어는 유저 가이드에 포함하지 않았습니다.
:::
