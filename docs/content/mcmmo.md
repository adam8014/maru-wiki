# 🏆 mcMMO — 플레이할수록 성장하는 실력

**mcMMO**는 채광, 벌목, 전투, 낚시 등의 행동에 성장 요소를 더하는 플러그인입니다.

## 어떤 플레이를 하면 좋을까요?

- ⛏️ 채광을 통해 관련 스킬 성장 경험하기
- 🪓 나무를 베며 벌목 계열 스킬 익히기
- 🎣 낚시를 통해 생활 활동 즐기기
- ⚔️ 무기를 사용하며 전투 스킬 경험하기

## 자주 쓰는 기본 명령어

| 명령어 | 설명 |
| --- | --- |
| `/mcstats` | 자신의 스킬 통계 확인 |
| `/mctop` | 스킬 랭킹 보기 |
| `/mcability` | 능력 활성화 설정(권한·설정에 따라 다름) |

:::note 서버 설정 확인 중
활성 스킬, 경험치 배율, 능력 지속 시간 및 명령어 권한은 마루 서버의 최종 mcMMO 설정을 확인해 추가합니다.
:::
