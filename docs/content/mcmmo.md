# 🏆 mcMMO 성장 가이드

마루에서는 평범한 생존 활동도 성장으로 이어져요. **블록을 캐고, 나무를 베고, 낚시하고, 몬스터와 싸우면** 관련 mcMMO 스킬 경험치를 얻습니다.

:::tip 첫 접속 추천 코스
나무를 베어 집을 마련하고 → 채광으로 도구를 만들고 → 낚시와 농사를 즐기며 → 모험을 떠나 보세요.
:::

## 먼저 내 레벨 확인하기

| 명령어 | 사용법 |
| --- | --- |
| `/mcstats` | 나의 스킬 레벨과 성장 상태 보기 |
| `/mctop` | 성장 랭킹 살펴보기 |
| `/mcability` | 특수 능력 사용 설정(권한 허용 시) |

## ⛏️ 채집·생활 스킬

| 스킬 | 어떻게 키우나요? | 대표적인 특징 |
| --- | --- | --- |
| 채광 Mining | 돌과 광물 채굴 | **Super Breaker** 등 채굴 능력 |
| 벌목 Woodcutting | 나무 베기 | **Tree Feller** 나무 벌목 능력 |
| 발굴 Excavation | 흙·모래·자갈 파기 | **Giga Drill Breaker** |
| 약초학 Herbalism | 작물과 식물 수확 | **Green Terra** 등 작물 관련 능력 |
| 낚시 Fishing | 낚싯대로 낚시 | 낚시 관련 보너스 |
| 수리 Repair | 관련 수리 활동 | 도구와 방어구 수리 |
| 연금술 Alchemy | 물약 양조 | 양조 관련 보너스 |
| 제련 Smelting | 채광·수리 성장과 연계 | 제련 관련 보너스 |
| 재활용 Salvage | 수리·낚시 성장과 연계 | 장비 재료 회수 |

## ✨ 특수 능력이란?

일부 스킬에는 **Super Ability**가 있어요. 예를 들어 벌목은 *Tree Feller*, 채광은 *Super Breaker*를 사용할 수 있습니다. 발동 방식과 지속 시간, 재사용 대기시간은 서버 설정 및 mcMMO 버전에 따라 달라집니다.

:::note 마루 기본 설정 안내
이 문서는 **mcMMO 공식 기본 시스템**을 기준으로 설명합니다. 마루에서 일부 스킬이 비활성화되거나 권한이 제한될 수 있어요. 관리자 설정값이나 운영 명령어는 안내하지 않습니다.
:::
