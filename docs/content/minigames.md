# 🎮 마루 미니게임

생존 말고도 친구들과 함께 경쟁해 보세요! 마루의 미니게임은 **CS어택·TNT런·배드워즈** 세 가지로 소개합니다.

| 미니게임 | 목표 | 처음 볼 페이지 |
|---|---|---|
| 🔫 CS어택 | 커스텀 총기를 이용한 경기 | [CS어택 안내](./weapons.md) |
| 💣 TNT런 | 사라지는 바닥 위에서 끝까지 살아남기 | [TNT런 안내](./tntrun.md) |
| 🛏️ 배드워즈 | 침대 방어와 상대 팀 침대 파괴 | [배드워즈 안내](./bedwars.md) |

:::tip
게임 시작 전에 인벤토리를 정리하고 서버 리소스팩이 적용되어 있는지 확인하세요.
:::
