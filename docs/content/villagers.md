# 🧑‍🌾 ClickVillagers — 주민 이용 가이드

마루 서버는 주민 관련 편의 플러그인 **ClickVillagers**를 사용합니다.

주민을 관리하거나 상호작용하는 방법은 플러그인 버전과 운영 설정에 따라 달라집니다.

## 이용 전 알아두기

- 일반 주민과 거래할 때는 주민을 클릭합니다.
- 주민의 거래 품목과 가격은 서버 정책에 따라 다를 수 있습니다.
- 주민 이동·보관·소유권 관리 등 ClickVillagers의 실제 허용 기능은 운영 서버 설정을 확인한 뒤 안내합니다.

:::caution 확인 중인 항목
ClickVillagers의 실제 유저 명령어, 클릭 방식과 권한은 아직 확정하지 않았습니다. 확인되지 않은 조작법은 임의로 안내하지 않습니다.
:::
