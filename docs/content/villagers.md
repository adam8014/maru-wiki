# 🧑‍🌾 ClickVillagers — 주민을 간편하게 관리해 보세요!

마루 서버에서는 **ClickVillagers**로 주민을 이동시키거나 보호하고, 거래 정보를 더 편리하게 확인할 수 있습니다. 이 페이지는 [제작자 공식 사용법](https://modrinth.com/plugin/clickvillagers)을 기준으로 작성했어요.

:::tip 제일 먼저 기억하세요
**쉬프트(웅크리기) + 마우스 오른쪽 클릭**이 기본 조작입니다. 손에 든 아이템에 따라 기능이 달라져요.
:::

## 🎒 1. 주민을 아이템으로 줍고 배치하기

1. 주민 앞에서 **아무 도구도 들지 않은 상태로** 쉬프트를 누르고 **우클릭**하세요.
2. 주민이 인벤토리의 **주민 머리 아이템**으로 들어옵니다.
3. 원하는 위치에 주민 머리를 설치하면 다시 주민이 나타납니다.

- 주민을 보트나 광산 수레에 직접 배치할 수 있습니다.
- Paper/Spigot 1.21 이상에서는 발사기로 주민을 자동 배치할 수도 있습니다.
- 보호된 주민은 주인 외의 플레이어가 집을 수 없도록 제한될 수 있습니다.

:::caution
인벤토리에 빈 공간을 확보하고, 귀중한 주민은 안전한 곳에서 먼저 시험해 보세요. 실제 픽업 권한과 쿨타임은 서버 설정에 따릅니다.
:::

## 📜 2. 주민을 줍기 전에 거래 목록 확인하기

주민을 주운 후 인벤토리에서 **주민 머리 아이템에 마우스를 올려 보세요.**

- 주민의 직업과 관련된 주요 거래 목록이 표시됩니다.
- 사서라면 인챈트된 책 거래를 중심으로 확인할 수 있습니다.
- 소유자, 거래 가능 상태, 고정 상태도 표시될 수 있습니다.

직업별 거래 내용을 하나하나 직접 열어 보지 않고도 주민을 비교할 때 유용합니다.

## ✂️ 3. 가위로 주민 위치 고정하기

1. **가위**를 손에 듭니다.
2. 주민을 향해 **쉬프트 + 우클릭**합니다.
3. 고정된 주민은 **스스로 걸어 다니지 못하지만**, 외부에서 밀면 움직일 수 있습니다.

거래소나 주민 홀을 정리할 때 유용합니다.

## 🛡️ 4. 삽으로 주민 소유권 등록하기

1. 아무 종류의 **삽**을 듭니다.
2. 주민에게 **쉬프트 + 우클릭**하여 소유권을 등록합니다.
3. **삽을 계속 손에 든 상태로** 등록한 주민에게 **쉬프트 + 우클릭**하여 관리 메뉴를 엽니다.

관리 메뉴에서는 설정과 권한에 따라 다음을 이용할 수 있습니다.

- 🌍 주민의 바이옴 유형 변경
- 🔐 주민 거래 열기/닫기
- 🤝 거래 파트너 추가 및 관리
- 🛡️ 다른 플레이어로부터 주민 보호

기본 설정에서는 소유한 주민이 피해를 받지 않도록 보호하는 기능이 있습니다. 단, 마루 서버에서 이 보호 설정을 변경했을 가능성은 확인이 필요합니다.

## ⚙️ 5. 주민 자동 수집 호퍼 제작하기

![주민 호퍼 제작 재료: 호퍼 1개와 에메랄드 1개](/img/villager-hopper-guide.svg)

*재료를 이해하기 위한 안내 그림이며, 정확한 제작대 칸 배치를 뜻하지는 않습니다.*

Paper/Spigot에서는 **호퍼 1개 + 에메랄드 1개**를 조합해 주민 호퍼를 제작하는 기능이 제공됩니다.

주민 호퍼는 주민을 자동으로 수집할 수 있어 주민 번식장 관리에 도움이 됩니다.

:::info 기본 예외
공식 기본 설정에서는 **아기 주민과 소유권이 등록된 주민은 자동 수집하지 않습니다.** 조합 방식과 사용 가능 여부는 서버 설정에 따라 달라질 수 있습니다.
:::

## 🔄 6. 주민 거래 리셋 기능

플러그인에는 거래 화면에서 `Reset Trades` 항목을 이용해 거래를 초기화하는 **선택 기능**이 있습니다.

:::warning 기본적으로 꺼져 있는 기능
공식 설명에 따르면 거래 리셋은 기본 비활성화입니다. **마루 서버에서 사용 가능하다고 확인된 것은 아니므로** 일반 유저 기능으로 단정하지 않습니다.
:::

## 🎮 조작법 한눈에 보기

| 하고 싶은 일 | 조작 방법 |
|---|---|
| 주민 줍기 | 빈손으로 **쉬프트 + 우클릭** |
| 주민 다시 배치 | 주민 머리 아이템 설치 |
| 주민 거래 정보 미리보기 | 주민 머리 아이템에 마우스 올리기 |
| 주민 위치 고정 | **가위 + 쉬프트 + 우클릭** |
| 주민 소유권 등록 | **삽 + 쉬프트 + 우클릭** |
| 내 주민 관리 메뉴 | **삽을 들고** 등록된 주민에게 **쉬프트 + 우클릭** |
| 주민 자동 수집 | 주민 호퍼 활용(설정에 따름) |

:::note 마루 서버 안내
이 문서는 플러그인 공식 기능을 설명합니다. **마루에서 실제 허용된 기능과 권한은 최종 설정 파일을 확인한 뒤 업데이트**합니다.
:::

## ❓ 자주 묻는 질문

### 쉬프트 + 우클릭했는데 주민을 줍지 못해요.
주민이 다른 플레이어에게 소유권 등록되었거나, 서버에서 픽업을 제한했을 수 있어요. 빈손과 인벤토리 공간도 확인해 주세요.

### 주민을 설치하면 거래가 사라지나요?
일반적인 주민 픽업·설치 기능은 주민을 이동·보관하기 위한 것입니다. 중요한 거래 주민은 안전한 곳에서 먼저 테스트해 주세요.

### 주민이 움직이지 않아요.
가위로 고정한 상태인지 확인해 보세요.
