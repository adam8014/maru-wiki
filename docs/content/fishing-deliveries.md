# 🚚 낚시 배달 — 물고기를 모아 보상받기

PyroFishingPro의 **Deliveries**는 커스텀 물고기를 모아 의뢰를 완수하고 보상을 받는 콘텐츠입니다.

## 배달 의뢰 진행 방법

1. `/fish menu` 또는 `/fish deliveries`를 열어 의뢰를 확인합니다.
2. 필요한 **물고기 종류와 수량**을 확인합니다.
3. 해당 커스텀 물고기를 낚거나 다른 유저와 거래해 준비합니다.
4. 요구 조건을 만족하면 배달을 시작합니다.
5. 의뢰에 표시된 처리 시간이 지난 다음 메뉴에서 보상을 받습니다.

## 어떻게 의뢰를 얻나요?

공식 기본 안내에서는 **커스텀 물고기를 일정 수 낚을 때마다 새 의뢰**를 받습니다. 일반 바닐라 물고기는 진행 횟수에 포함되지 않습니다. 공식 FAQ에는 기본값 **180마리**로 안내되지만, 마루 서버의 실제 요구량은 게임 내 배달 메뉴를 기준으로 확인하세요.

## 도움말

- `/fish deliveries` : 배달 의뢰 목록 열기
- `/fish codex` : 요구되는 물고기 도감 찾기
- `/fish bag` : 보관 중인 물고기 확인

:::tip
배달에 필요한 희귀 물고기를 무작정 판매하지 말고, 먼저 의뢰 목록을 확인하는 습관을 들여 보세요.
:::
