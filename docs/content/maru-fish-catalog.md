# 🐟 마루 한국 물고기 도감

## 낚시할 때 알아두세요

- **등급**은 커스텀 물고기의 희귀도 단계예요.
- 한국 물고기 24종은 기존 PyroFishingPro 물고기에 **추가된 종류**입니다.
- 미끼, 판매 가격, 출현 확률은 서버 설정이 우선하므로 게임 내 메뉴를 확인하세요.
- 이미지 속 물고기는 **실제 마루 리소스팩 텍스처**이며, 화면 가독성을 위해 확대했어요.
