# 🌾 특수작물 가이드

마루의 농사는 **CustomCrops**를 사용합니다. 씨앗을 심고, 물을 주고, 계절에 맞춰 수확하는 생활 콘텐츠예요.

## 🌱 기본 제공 작물 13종

| 작물 | 작물 | 작물 |
|---|---|---|
| 🧄 마늘 | 🌿 홉 | 🍆 가지 |
| 🥬 양배추 | 🥬 배추 | 🌶️ 고추 |
| 🍅 토마토 | 🍎 사과나무 | 🐉 용과 |
| 🍇 포도 | 🌽 옥수수 | 🧧 복주머니 나무 |
| 🍍 파인애플 |  |  |

마루는 CustomCrops 기본 작물 구성을 사용하고 있어요. 위 목록은 **플러그인의 기본 제공 프리메이드 에셋 13종** 기준입니다.

## ☀️ 계절별 재배

작물은 봄·여름·가을·겨울 중 **자기에게 맞는 계절**에 심고 키워야 합니다.

| 계절 | 작물 선택 |
|---|---|
| 🌸 봄 | **토마토**를 심을 수 있어요. 나머지 작물은 씨앗 설명의 계절 표시를 확인하세요. |
| ☀️ 여름 | 현재 계절에 적합하다고 표시된 작물을 선택하세요. |
| 🍁 가을 | **토마토**를 심을 수 있어요. 나머지 작물은 씨앗 설명을 확인하세요. |
| ❄️ 겨울 | 겨울 재배가 가능한 작물이나 온실을 활용하세요. |

:::important
**토마토는 공식 기본 설정에서 봄·가을 재배**가 확인됩니다. 나머지 12종의 계절 지정은 기본 에셋 이미지 목록만으로는 확정할 수 없어 임의의 계절을 배정하지 않았습니다. 게임의 씨앗 설명과 계절 표시를 확인해 주세요.
:::

## 🪴 재배 순서

1. 커스텀 씨앗과 **전용 경작지(Pot)**를 준비하세요.
2. 경작지를 설치하고 씨앗을 심습니다.
3. **물뿌리개(Watering Can)**로 물을 주거나 스프링클러를 사용합니다.
4. 작물의 성장 상태와 계절을 살펴보세요.
5. 충분히 자라면 수확합니다. 작물에 따라 다시 자라는 방식이 다를 수 있어요.

## 💧 물뿌리개와 스프링클러

- **물뿌리개**: 물을 담아 전용 경작지에 직접 물을 줍니다.
- **스프링클러**: 설치해 두면 주변 작물에 물을 공급합니다.
- 스프링클러에 물을 채우는 방법과 범위는 설치된 아이템의 설명을 확인하세요.
- 물이 부족한 밭은 성장 속도에 영향을 받을 수 있습니다.

## 🪶 허수아비와 까마귀

까마귀가 농작물을 공격할 수 있어요. 농장 근처에 **허수아비**를 설치해 작물을 보호하세요. 설치 위치와 보호 범위는 서버 안의 아이템 설명을 참고하세요.

## 🏡 온실 만들기

해당 계절에 맞지 않는 작물도 **온실 유리(Greenhouse Glass)**로 적절히 보호하면 재배할 수 있어요.

1. 온실용 재료를 준비합니다.
2. 작물을 재배할 공간을 온실 유리로 꾸밉니다.
3. 실내에 전용 경작지와 급수 수단을 마련합니다.
4. 계절이 맞지 않는 작물이 정상적으로 자라는지 확인하세요.

:::note
온실의 정확한 판정 범위·필수 배치 규칙과 아이템 조합법은 마루의 실제 CustomCrops 아이템 설정에 따릅니다. 일반 유리만 설치하면 온실이 된다고 안내하지 않습니다.
:::

## ✨ 비료로 농사 효율 높이기

비료에는 성장 속도 보조, 수분 유지, 수확 품질 향상, 수확량 증가처럼 **서로 다른 효과**가 있습니다. 필요한 작물에 알맞은 비료를 사용하세요.

## 🛡️ 농장 보호와 블록 조사

다른 사람의 농장을 허락 없이 훼손하지 마세요. 수상한 변경 기록이 있다면 [CoreProtect `/co i`](/guide/systems/coreprotect)로 확인할 수 있어요.
