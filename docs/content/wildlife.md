# 🦌 마루 야생동물 — 30종 발견 도감

마루 월드에는 사슴·카피바라·펭귄·수달 등 **새로운 야생동물 30종**이 살고 있어요. 주변을 탐험하며 처음 보는 동물을 발견하고 도감을 채워보세요!

이 동물들은 **별도 클라이언트 모드나 추가 리소스팩 설치 없이** 마루 서버에서 제공하는 블록 디스플레이 모델로 표시됩니다. 동물마다 어울리는 바이옴·먹이·습성이 달라요.

마루의 숲과 초원, 사막, 정글, 설원과 물가에는 각기 다른 모습의 동물 30종이 살고 있어요. 아래 도감에서 **동물별 서식지와 좋아하는 먹이**를 확인하고 직접 만나보세요.

## 📖 동물도감 여는 법

**`/동물도감`** 또는 **`/animalbook`**을 입력하세요.

- 주변 **10블록 이내**의 동물을 **직접 볼 수 있을 때** 자동으로 발견됩니다.
- 발견 기록은 플레이어별로 저장되며, **30종을 수집하는 탐험 목표**로 즐길 수 있습니다.
- 도감은 읽기 전용 GUI이므로 아이템을 꺼내거나 옮길 수 없습니다.

## 🎲 자연 스폰 확률 — 정확히 어떻게 적용되나요?

| 항목 | 현재 설정 |
|---|---|
| 야생동물 추가 스폰 시도 | **자연 스폰 이벤트당 2%** |
| 설정 가능한 추가 확률 상한 | **5%** |
| 근처 동물 밀도 제한 | **32블록 안에 8마리** |
| 로드된 동물 수 한도 | **128마리** |
| 기본 스폰 환경 | 오버월드의 적합한 자연 환경 |
| 기본 제외 월드 | 네더, 엔드 |

**2%는 사슴 2%, 수달 2%처럼 종별 확률을 각각 더하는 방식이 아닙니다.** 바닐라 수동·수생 동물의 **정상적인 자연 생성 이벤트**가 일어났을 때, 추가 동물을 생성할지 먼저 2% 확률로 판단하고 **그 바이옴에 맞는 종**을 선택합니다.

따라서 **종별 고정 스폰 확률은 현재 별도로 공개된 수치가 없어요.** 해당 지역에 서식하는 후보 동물, 실제 자연 스폰 빈도와 주변 개체 수에 따라 만날 기회가 달라집니다.

- 바닐라 동물을 없애거나 대신 출현시키는 방식이 아니라 **추가 스폰**입니다.
- 바닐라 자연 스폰이 없는 장소에서는 정기적으로 동물이 새로 생기지 않습니다.
- 이미 탐험한 지역에 접속했다고 동물이 즉시 출현하는 것은 아닙니다.
- 보호·이벤트 취소 등의 조건에 따라 생성이 제한될 수 있어요.

## 🥕 먹이 주기와 번식

1. 표에서 동물이 좋아하는 **먹이**를 준비합니다.
2. 같은 종의 **성체 두 마리**에게 각각 먹이를 들고 **우클릭**합니다.
3. 두 동물은 약 **60초 동안** 서로 가까이 이동해 새끼를 낳으려고 합니다.
4. 번식 후 부모에게는 약 **5분간 대기시간**이 생깁니다.
5. 태어난 새끼는 성체 크기의 **약 60%**이고, 활성 상태에서 약 **20분**이 지나면 성장합니다.
6. 새끼에게 먹이를 주면 남은 성장 시간이 **1회당 약 1분** 줄어듭니다.

:::note
서로 다른 종끼리는 번식할 수 없어요. 청크가 언로드되어 동물이 활성 상태가 아니면 성장 시간이 진행되지 않습니다. 스폰·번식은 서버 동물 수 제한도 적용됩니다.
:::

## 🐾 동물들의 습성

- **주변 탐색과 배회**: 종마다 이동 속도와 걸음걸이, 머리·꼬리·날개 움직임이 다릅니다.
- **위협 회피와 휴식**: 위험하면 도망가거나 쉬기도 합니다.
- **물가 생활**: 일부 종은 물속을 헤엄치도록 행동합니다.
- **무리 행동과 먹이 추종**: 같은 종과 어울리거나 먹이를 든 플레이어를 따라갈 수 있습니다.
- **일부 포식자**: 이름 없는 일반 토끼·닭·물고기를 공격할 수 있어요. **플레이어, 길들인 동물, 이름 붙인 동물, 마루 추가 동물은 포식 대상이 아닙니다.**
- 식물을 찾아가는 행동은 있지만, **농작물이나 블록을 자동으로 파괴하거나 소비하지 않습니다.**

:::warning 다른 모드·플러그인과의 호환
실제 운영 서버의 **Residence 땅 보호 플래그, 몹 합치기(Stacker)** 설정과는 통합 검증되지 않았습니다. 새 동물이 보이지 않거나 합쳐지는 문제가 있다면 관리자에게 알려주세요.
:::

## ❓ 자주 묻는 질문

**Q. 아무리 돌아다녀도 안 보여요.**  
동물이 적합한 바이옴에만 나타나고, 자연 스폰 이벤트당 2% 추가 시도이며 근처 동물 수 제한이 적용되므로 드물게 보일 수 있어요.

**Q. 도감에 등록하려면 죽이거나 잡아야 하나요?**  
아니요. **10블록 이내**에서 시야가 닿도록 가까이 가면 자동으로 발견됩니다.

**Q. 미니맵이나 리소스팩을 따로 설치해야 하나요?**  
아니요. 동물 모델은 서버 자체 기능을 사용합니다. 다만 게임·서버 버전 호환은 운영 공지를 확인하세요.

**Q. 동물을 잡으면 특별 아이템을 주나요?**  
이 버전에 **전용 드롭 아이템 목록이나 별도 경제 보상 금액은 정의되지 않았습니다.** 임의의 드롭이나 보상은 안내하지 않습니다.

**Q. 특정 동물이 언제·어디서 반드시 나오나요?**  
정해진 시간·좌표에 출현을 보장하지 않아요. 지역별 **자연 생성 조건과 확률**에 따라 달라집니다.
