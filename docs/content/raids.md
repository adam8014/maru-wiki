# 🐉 레이드와 모험

친구들과 힘을 합쳐 새로운 전투를 즐기고 싶다면 레이드 콘텐츠를 확인해 보세요.

## 처음 도전할 때

1. 장비와 식량을 충분히 준비합니다.
2. 함께 싸울 파티원과 역할을 정합니다.
3. 입장 조건과 참가 방법은 게임 내 공지를 확인합니다.
4. 전투가 시작되면 서로의 위치와 체력을 살펴 협력합니다.

:::note 콘텐츠 안내
마루에서는 레이드 관련 플러그인을 검토·운영한 기록이 있습니다. **현재 활성화된 보스, 위치, 입장 조건, 보상**은 아직 확정된 자료가 없어 기재하지 않았습니다.
:::
