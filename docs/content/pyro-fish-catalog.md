# 🐠 PyroFishingPro 기본 물고기 126종 도감

마루 서버는 **PyroFishingPro 기본 물고기 126종**에 별도로 추가된 **마루 한국 물고기 24종**을 더해, 설정상 총 **150종의 커스텀 물고기**를 제공합니다.

이 페이지의 이름과 등급 및 서식 바이옴은 마루 서버에서 사용했던 **fish.yml (2026-10-04 확인본)** 기준입니다. 서버 설정이 변경되었다면 실제 게임의 `/fish codex`가 우선입니다. 기본 물고기 이름은 해당 설정 파일에 있는 한국어 이름을 그대로 사용했습니다.

- [마루 한국 물고기 24종 (별도 추가)](./maru-fish-catalog.md)
- [낚시 방법과 각종 메뉴](./fishing.md)

:::tip 도감에서 찾기
게임에서 `/fish codex`를 열면 물고기별 실제 획득 조건을 확인할 수 있습니다. 아래 표의 바이옴은 **설정 파일에 지정된 장소**이며, 획득 확률·미끼·지역별 제한은 실제 서버 설정이 우선합니다.
:::
