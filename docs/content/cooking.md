# 🍳 마루의 식탁 — 요리 가이드

**마루 요리 1.2.0**은 PyroFishingPro로 잡은 물고기와 CustomCrops 농작물로 음식을 만드는 전용 콘텐츠입니다.

## 🎮 요리책 열기

채팅에서 **`/요리`**를 입력하세요. **`/마루요리`**, **`/요리책`**, **`/marucuisine`**도 같은 요리책을 엽니다.

요리책은 **조합법을 확인하는 메뉴**입니다. 음식 항목을 클릭하면 재료와 수량, 완성 음식의 효과를 볼 수 있지만, **요리책에서 직접 제작하지는 않습니다.**

## 🧰 실제 음식은 제작대에서 만들어요!

1. `/요리`를 열고 만들 음식을 클릭해 필요한 재료와 개수를 확인합니다.
2. 요리책을 닫고 **일반 제작대의 3×3 조합칸**을 엽니다.
3. 필요한 재료를 **하나의 칸마다 1개씩** 나눠 배치합니다. **배치 순서는 자유**입니다.
4. 완성 칸에 음식이 나타나면 **좌클릭/우클릭으로 1개 제작**, **Shift+클릭으로 여러 개 제작**할 수 있습니다. 기본 한 번에 최대 **16개**까지 가능하며 재료와 인벤토리 공간이 충분해야 합니다.

### 예: 바삭 생선튀김

| 필요한 재료 | 제작대에 배치할 칸 |
|---|---|
| 커스텀 물고기 1마리 | 칸 1개 |
| 밀 2개 | **서로 다른 칸 2개** |

**밀 두 개를 한 칸에 겹쳐 놓는 것은 두 칸을 채운 것으로 인정되지 않아요.** 아래는 가능한 한 예시입니다.

```text
[ 커스텀 물고기 ] [ 밀 ] [ 밀 ]
[      빈칸     ] [빈칸] [빈칸]
[      빈칸     ] [빈칸] [빈칸]
```

### 제작할 때 주의할 점

- 반드시 **3×3 제작대**를 사용하세요. 개인 인벤토리 **2×2 조합창**에서는 만들 수 없어요.
- 레시피에 없는 재료를 추가하면 결과물이 나오지 않습니다.
- 일반 물고기가 아닌 **PyroFishingPro 커스텀 물고기 총 150종**을 공통 생선 요리에 사용할 수 있어요. 특정 어종 요리는 해당 물고기가 필요합니다.
- **CustomCrops 작물은 일반·은별·금별 품질** 모두 재료로 사용할 수 있습니다. 단순히 이름만 바꾼 일반 아이템은 인정되지 않아요.
- 비싼 물고기를 공통 생선 요리에 넣어도 **해당 물고기가 그대로 소모**되니 주의하세요.
- 바닐라 초록색 레시피북 자동 채우기와 자동 제작기(Crafter)는 지원하지 않습니다.
- **요리책은 재료를 소비하지 않습니다.** 재료는 제작대에서 실제 제작할 때만 소모됩니다.

:::tip 크리에이티브 모드 관리자용 기능
**OP이면서 크리에이티브 모드**인 운영자는 요리책의 음식 항목을 **가운데 클릭**해 한 스택을 받을 수 있습니다. 일반 유저와 생존 모드에서는 사용할 수 없는 기능입니다.
:::

## ✨ 음식 버프는 어떻게 적용되나요?

요리를 먹으면 음식별로 서로 다른 포만감과 효과가 적용될 수 있습니다. 예를 들어 **맑은 참돔탕은 재생**, **감성돔 회 한 접시는 야간 투시**, **붕장어 양념구이는 신속** 효과가 설정되어 있습니다. 정확한 지속 시간은 위 표를 확인하세요.

:::info 실제 게임 화면 기준
텍스처 최종 수정 **1.0.2**는 음식과 GUI가 깨지지 않도록 수정한 리소스팩 호환 패치입니다. 이 문서는 **1.0 레시피 데이터**를 기준으로 작성했으며, 게임 내 요리 GUI의 완성 아이템 외형은 서버 리소스팩 적용 후 확인할 수 있습니다.
:::
