# 🍳 마루의 식탁 — 요리 가이드

**마루 요리 1.0**은 PyroFishingPro로 잡은 물고기와 CustomCrops 농작물로 음식을 만드는 전용 콘텐츠입니다.

## 🎮 요리책 열기

채팅에서 **`/요리`**를 입력하세요. **`/마루요리`**, **`/요리책`**도 같은 요리 시스템을 여는 명령어입니다.

요리책에서 만들고 싶은 메뉴를 고르고 필요한 재료와 수량을 확인한 후 제작하세요. 플러그인은 실제 물고기의 데이터와 CustomCrops 아이템 ID를 구분하므로, **이름이 비슷한 바닐라 물고기나 장식 아이템은 재료로 인정되지 않을 수 있습니다.**

:::tip 여러 개 만들고 싶다면
설정상 한 번에 제작할 수 있는 최대 수량은 **16개**입니다. 인벤토리에 재료와 결과물 공간을 확보해 주세요.
:::

- [CustomCrops 농사 가이드](./farming.md)를 참고해 마늘·고추·토마토·옥수수·포도·용과 등 필요한 작물을 기르세요.
- 일반 품질뿐 아니라 은별·금별 품질의 CustomCrops 수확물도 인식하도록 설정되어 있습니다.

## ✨ 음식 버프는 어떻게 적용되나요?

요리를 먹으면 음식별로 서로 다른 포만감과 효과가 적용될 수 있습니다. 예를 들어 **맑은 참돔탕은 재생**, **감성돔 회 한 접시는 야간 투시**, **붕장어 양념구이는 신속** 효과가 설정되어 있습니다. 정확한 지속 시간은 위 표를 확인하세요.

:::info 실제 게임 화면 기준
텍스처 최종 수정 **1.0.2**는 음식과 GUI가 깨지지 않도록 수정한 리소스팩 호환 패치입니다. 이 문서는 **1.0 레시피 데이터**를 기준으로 작성했으며, 게임 내 요리 GUI의 완성 아이템 외형은 서버 리소스팩 적용 후 확인할 수 있습니다.
:::
