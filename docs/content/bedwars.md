# 🛏️ 배드워즈 — 침대를 지켜 승리하세요!

배드워즈는 자원을 모아 장비를 사고, **우리 팀 침대를 지키면서 상대 팀 침대를 부수는** 팀 전투 미니게임입니다.

## 게임 방법

1. 대기실에서 경기에 참가합니다.
2. 팀 섬에서 자원을 모읍니다.
3. 상점에서 블록·무기·방어구 등을 준비합니다.
4. 블록으로 다리를 만들어 다른 섬을 탐험합니다.
5. 우리 침대를 보호하면서 상대 침대를 파괴하세요.
6. 상대 팀을 모두 탈락시키면 승리합니다.

## 중요한 규칙

- **침대가 살아 있는 동안에는** 죽어도 부활할 수 있습니다.
- **침대가 부서지면** 이후 죽었을 때 더 이상 부활할 수 없습니다.
- 혼자 돌격하기보다 공격·수비·자원 수집 역할을 나누면 좋아요.

## 마루 경기장

마루 서버에서는 **MaruDuel**, **MaruSky** 경기장을 로드한 기록이 있습니다. 실제 운영 중 선택 가능한 경기장과 참가 방식은 게임 내 안내를 따라 주세요.

:::note
현재 경기 방식과 입장 명령어는 실제 서버 최종 설정을 확인한 뒤 추가합니다.
:::
