# 🛏️ 배드워즈

**BedWars**는 침대를 지키면서 상대 팀을 상대하는 팀 기반 미니게임입니다. 마루 서버에 관련 플러그인이 설치된 기록이 있습니다.

## 기본 플레이 흐름

1. 게임에 참가하고 팀을 선택합니다.
2. 자원을 모아 장비와 블록을 확보합니다.
3. 우리 팀 침대를 보호합니다.
4. 상대 팀 침대를 파괴하고 상대 팀을 처치합니다.

:::tip
혼자 공격하기보다 한 명은 수비, 다른 팀원은 자원 확보와 공격을 맡으면 좋아요.
:::

:::note
정확한 입장 명령어와 현재 경기장 운영 상태는 서버에서 확인 후 안내합니다.
:::
