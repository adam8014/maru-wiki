# 🗼 낚시 토템 — 나만의 낚시 명당 만들기

PyroFishingPro의 **Fishing Totem**은 근처에서 낚시할 때 여러 보너스를 얻을 수 있는 멀티블록 구조물입니다.

## 먼저 준비할 재료

| 재료 | 수량 |
|---|---:|
| 🐬 돌고래 꼬리 (Dolphin Tail) | **16개** |
| 🦀 게 집게발 (Crab Claw) | **16개** |
| 🦀 게 비늘 (Crab Scale) | **16개** |
| 🦑 오징어 촉수 (Squid Tentacle) | **16개** |
| 🐟 플래티넘 등급 물고기 | **6마리** |

**낚시 레벨 20 이상**이어야 활성화할 수 있습니다. `/fish stats`로 레벨을 확인하세요.

## 🧱 토템 조립하기

1. `/fish menu`에서 **토템 구조물 안내 그림**을 엽니다.
2. 화면에 표시된 블록 구조와 방향을 그대로 따라 만들어 보세요.
3. 필요한 재료 5종이 모두 준비됐는지 확인합니다.
4. 낚싯대를 들고 **가장 아래쪽 관측기(Observer)**를 때리면 활성화할 수 있습니다.
5. 활성화되지 않는다면 게임에서 표시되는 부족 재료·구조 오류 안내를 확인하세요.

:::tip 공식 구조 그림 확인하기
블록 배치는 글만 보고 만들면 헷갈릴 수 있습니다. **[PyroFishingPro 공식 토템 조립 그림 및 설명](https://pyrotempus.gitbook.io/pyro-plugins/pyrofishingpro/features/fishing-totem)**을 함께 보세요. 실제 게임에서는 `/fish menu`의 구조 그림이 가장 정확합니다.
:::

## 활성화 후에는?

토템 범위 내에서 낚시할 때 보너스를 받을 수 있으며, 엔트로피를 사용해 토템 능력을 강화할 수 있습니다. 구체적인 효과와 슬롯은 게임 내 토템 메뉴에서 확인하세요.

**공식 참고:** [Fishing Totem](https://pyrotempus.gitbook.io/pyro-plugins/pyrofishingpro/features/fishing-totem)
