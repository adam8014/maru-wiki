# 💰 마루 활동 보상 — 플레이하면서 돈 벌기

마루에서는 단순히 아이템을 팔지 않아도 **생활·탐험 활동으로 경제 보상**을 받을 수 있어요. 채굴, 건축, 아이템 제작, 낚시, 이동과 게임 플레이에 따라 돈이 지급되며, 보상은 서버 경제(LiteEco)에 쌓입니다.

## 🪙 활동별 기본 보상표

| 활동 | 조건·대상 | 기본 보상 |
|---|---|---:|
| ⏱️ 플레이 활동 | 활동 중 **60초마다** | **0.25원** |
| ⛏️ 일반 돌 채굴 | 돌(STONE) 1개 | **0.01원** |
| 🪨 석탄 광석 채굴 | 석탄 광석(COAL_ORE) 1개 | **0.05원** |
| 🔩 철 광석 채굴 | 철 광석(IRON_ORE) 1개 | **0.10원** |
| 💎 다이아몬드 광석 채굴 | 다이아몬드 광석(DIAMOND_ORE) 1개 | **0.50원** |
| ⛏️ 기타 블록 파괴 | 별도 보상값이 없는 블록 1개 | **0.01원** |
| 🧱 블록 설치 | 정상적인 월드에 블록 1개 설치 | **0.01원** |
| 🛠️ 아이템 제작 | 제작한 아이템 **1개당** | **0.05원** |
| 🎣 낚시 | 낚시 보상 1회 | **0.20원** |
| ✨ 인챈트 | 인챈트 활동 1회 | **0.25원** |
| 🧪 양조 | 양조 활동 1회 | **0.15원** |
| 🚶 이동·탐험 | 정상 이동 거리 **100블록당** | **0.10원** |

:::important 꼭 알아두세요
표는 설치된 **ActivityEconomy 1.0.0의 확인된 설정값**으로, 지급 전 **기본 보상**입니다. 실제 받는 돈은 시간당 누적 보상·감액·지급 한도·부정 이용 방지 규칙에 따라 더 작거나 0원이 될 수 있어요.
:::

## 📉 시간당 100원 제한

**1시간에 받을 수 있는 활동 보상은 최대 100원**으로 제한됩니다. 보상이 쌓일수록 지급액이 단계적으로 줄어들도록 설정되어 있어요.

| 시간당 누적 지급액 구간 | 설정된 지급 배율 |
|---|---:|
| 누적 50% 기준 | 100% |
| 누적 75% 기준 | 75% |
| 누적 90% 기준 | 40% |
| 누적 98% 기준 | 10% |
| 누적 100% 기준 | 0% |

활동 보상 외에 거래소에서 얻는 거래 대금 등은 **별도의 경제 활동**이므로, 이 표가 서버 전체 돈벌이 수단의 한도를 뜻하지는 않아요.

## 🛡️ 자동화·반복 악용 방지

- **직접 설치한 블록을 다시 파괴해도** 채굴 보상을 받지 못하도록 제한합니다.
- 자리 비움(AFK) 상태에서는 플레이 시간 및 일부 활동 보상이 차단됩니다.
- 낚시는 보상 사이에 **최소 2초 간격**이 적용됩니다.
- 이동은 순간이동이나 비정상적인 빠른 이동으로 보상을 반복 획득하지 못하도록 제한합니다.
- 제작은 이벤트당 최대 **64개**까지만 보상 대상으로 계산하며, 분당 보상 처리 제한도 있어요.
- 설정상 **creative, minigames** 월드에서는 이 보상을 지급하지 않습니다. 다른 미니게임 월드의 적용 여부는 실제 월드 이름과 서버 설정에 따릅니다.

## 🧭 초보자 추천: 이렇게 돈 모아보세요

1. **나무와 돌을 캐서** 기본 도구를 만드세요. 채굴과 제작 활동으로 소액 보상이 쌓입니다.
2. **철을 채굴해** 장비를 갖추고, 여유가 생기면 다이아몬드를 찾아보세요.
3. **낚시로 음식 재료**를 얻고 [마루 요리](../content/cooking.md)로 생존을 준비하세요.
4. **집터를 탐색**하면서 이동 보상을 받고, 집을 지을 때도 건축 활동 보상을 받을 수 있어요.
5. 자금을 모았다면 [Residence 땅 보호](../systems/residence.md)로 내 집터를 보호하세요.

:::tip 보상 금액 확인하기
지급될 때 화면 아래쪽 **액션바**에 보상액과 해당 시간의 누적 지급액이 표시되도록 설정되어 있습니다.
:::

이 안내는 마루 서버에서 사용한 `ActivityEconomy` 설정과 수정된 JAR, 서버 실행 로그를 확인해 작성했습니다. 서버 관리자가 보상 설정을 변경하면 실제 지급액도 달라질 수 있어요.
