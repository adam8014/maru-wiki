# ⌨️ 유저 명령어 모음

마루 서버에서 **일반 유저가 사용할 수 있거나, 공식 플러그인에서 제공하는 명령어**를 정리했습니다.

| 명령어 | 하는 일 | 비고 |
|---|---|---|
| `/co i` | 블록 기록 조사 켜기·끄기 | **마루 일반 유저 사용 가능** |
| `/mcstats` | 내 mcMMO 스킬 확인 | mcMMO 기본 명령어 |
| `/mctop` | mcMMO 랭킹 확인 | mcMMO 기본 명령어 |
| `/mcability` | mcMMO 특수 능력 설정 | 권한에 따라 다름 |
