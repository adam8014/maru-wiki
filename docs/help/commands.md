# ⌨️ 마루 유저 명령어 가이드

마루에서 자주 사용하는 명령어를 **이동 → 집 관리 → 콘텐츠 → 기록 조사** 순서로 정리했어요. 명령어는 채팅창을 열고 입력합니다.

## 🌸 서버 안내와 커뮤니티

| 명령어 | 설명 |
|---|---|
| `/가이드` | **마루 공식 위키** 주소를 확인하고 처음 접속·명령어·콘텐츠 사용법을 살펴봅니다. |
| `/디스코드` | **마루 디스코드** 접속 안내를 확인합니다. 공지, 질문, 커뮤니티 소통에 활용하세요. |

### 가이드가 필요할 때

채팅에 `/가이드`를 입력하세요. 마루 공식 위키의 주소 안내를 통해 처음 접속 가이드, 낚시, 농사, 요리와 미니게임 설명을 찾아볼 수 있어요.

**공식 위키:** [maru-wiki.pages.dev](https://maru-wiki.pages.dev/)

### 디스코드에 참여하고 싶을 때

채팅에 `/디스코드`를 입력하세요. 서버에서 안내하는 디스코드 연결 주소를 확인하고 안내에 따라 참여하면 됩니다.

**디스코드 안내 주소:** [discord.mygall.xyz](https://discord.mygall.xyz)

:::tip
두 명령어는 서버 정보를 빠르게 찾아볼 때 유용해요. 주소 안내의 표시 형태(채팅 링크·클릭 버튼 등)는 실제 서버 스크립트에 따라 달라질 수 있습니다.
:::

## 🧭 친구에게 이동하기 (TPA)

| 명령어 | 설명 |
|---|---|
| `/tpa 닉네임` | 상대방에게 **내가 이동하겠다**고 요청 |
| `/tpahere 닉네임` | 상대방을 **내 위치로 초대** |
| `/tpaccept` | 받은 요청 수락 |
| `/텔수락` | 수락 한글 별칭 |
| `/tpdeny` | 받은 요청 거절 |
| `/텔거절` | 거절 한글 별칭 |
| `/tpacancel` | 내가 보낸 요청 취소 |

### 친구에게 가려면?

1. 채팅에 `/tpa 친구닉네임`을 입력하세요.
2. 친구에게 **[수락] [거부]**를 클릭할 수 있는 요청 메시지가 표시됩니다.
3. 친구가 **[수락]**을 누르면 친구의 위치로 이동합니다.

### 친구를 나에게 부르려면?

1. `/tpahere 친구닉네임`을 입력하세요.
2. 친구가 요청을 수락하면 **친구가 내 위치로** 옵니다.

:::tip 요청은 60초 동안 유효해요
받은 요청은 60초 뒤 만료됩니다. 마루 텔레포트 스크립트에 한글 수락/거절 별칭과 클릭 버튼이 포함되어 있어요. 정확한 닉네임이나 사용 가능한 별명으로 입력하세요.
:::

## 🏠 나만의 집 저장하기

| 명령어 | 설명 |
|---|---|
| `/sethome 집이름` | 현재 서 있는 위치를 홈으로 저장 |
| `/home 집이름` | 지정한 홈으로 이동 |
| `/home` | 저장된 홈 확인 또는 홈 선택 화면 이용 |
| `/delhome 집이름` | 저장된 홈 삭제 (홈 관리 명령어) |
| `/back` | 이전 이동 위치로 돌아가기 |

### 집을 지정하고 이동하는 예시

1. 집 안의 안전한 위치에 서세요.
2. `/sethome 우리집`을 입력합니다.
3. 나중에 집으로 돌아오고 싶다면 `/home 우리집`을 입력하세요.

```text
/sethome 우리집
/home 우리집
```

일반 유저의 **기본 홈 저장 한도는 3개**로 구성했어요. 저장된 집 이름을 기억해두면 편리합니다.

:::note
홈을 삭제하는 `/delhome`은 일반적인 홈 관리 명령어이지만, 마루의 현재 플러그인 버전에서 동일한 문법인지 최종 확인이 필요합니다. `/back`의 이동 대상도 직전 텔레포트·사망 등 상황에 따라 달라질 수 있으니 게임 메시지를 확인하세요.
:::

## 💰 활동 보상 — 채굴·건축·낚시·이동

마루에서는 **플레이하면서 돈을 자동으로 받는 활동 보상 시스템**을 이용합니다.

| 행동 | 기본 지급액 |
|---|---:|
| 다이아몬드 광석 채굴 | 0.50원/개 |
| 철 광석 채굴 | 0.10원/개 |
| 석탄 광석 채굴 | 0.05원/개 |
| 돌 채굴 | 0.01원/개 |
| 블록 설치 | 0.01원/개 |
| 아이템 제작 | 0.05원/개 |
| 낚시 | 0.20원/회 |
| 인챈트 | 0.25원/회 |
| 양조 | 0.15원/회 |
| 이동 100블록 | 0.10원 |

기본 설정에서 **시간당 최대 100원**까지 지급하며, 시간당 누적 보상에 따라 실제 지급액이 줄어듭니다. 별도의 돈벌이 명령어를 입력할 필요 없이 정상적인 활동을 하면 자동으로 지급돼요.

## 🍳 요리와 음식 — 제작대 사용

| 명령어 | 설명 |
|---|---|
| `/요리` | 50종 음식의 **조합법과 효과를 보는 요리책** 열기 |

**사용법:** 요리책에서 음식을 클릭해 재료를 확인 → 요리책 닫기 → **3×3 제작대**에서 재료를 한 칸에 하나씩 놓아 제작합니다. 재료 배치 순서는 상관없고, Shift+클릭으로 기본 최대 16개까지 한 번에 제작할 수 있어요. **요리책에서는 직접 요리하지 않습니다.**

## 🗺️ 미니맵과 정보 HUD

마루 미니맵은 **지도와 정보창을 별도로** 표시할 수 있어요. 정보창에는 좌표, CustomCrops 계절, 게임 시간과 바이옴·통장 정보가 표시됩니다.

| 명령어 | 설명 |
|---|---|
| `/미니맵` | 미니맵 표시 켜기/끄기 전환 |
| `/미니맵 켜기` | 지도 표시 켜기 |
| `/미니맵 끄기` | **지도만 끄기** (정보창 유지) |
| `/미니맵 정보` | 좌표·계절·시간 등 정보창 표시 전환 |
| `/미니맵 정보 켜기` | 정보창 켜기 |
| `/미니맵 정보 끄기` | 정보창 끄기 |
| `/미니맵 왼쪽` | 지도와 정보창을 왼쪽에 배치 |
| `/미니맵 오른쪽` | 지도와 정보창을 오른쪽에 배치 |
| `/미니맵 도움말` | HUD 명령어 사용법 |

### 🎨 모드·셰이더 충돌이 발생한다면

일부 클라이언트 모드나 셰이더를 사용하면 **미니맵 그래픽이 겹치거나 깨지는 문제**가 발생할 수 있어요.

1. **`/미니맵 끄기`**를 입력해 지도만 숨기세요.
2. 좌표·계절·시간 정보가 필요하면 **`/미니맵 정보 켜기`**를 유지하세요.
3. 정보창도 충돌하면 **`/미니맵 정보 끄기`**로 함께 숨길 수 있어요.
4. HUD가 겹치면 **`/미니맵 왼쪽`** 또는 **`/미니맵 오른쪽`**으로 옮겨 보세요.
5. 셰이더를 끈 다음 **`/미니맵 켜기`**로 지도를 다시 표시할 수 있어요.

**개인 설정은 재접속해도 유지됩니다.** 충돌한다고 모드나 셰이더를 반드시 삭제할 필요는 없어요.

## 🏡 Residence 땅 보호

| 명령어 | 설명 |
|---|---|
| `/res ?` | 레지던스 명령어 도움말 |
| `/res select size` | 현재 선택한 땅 크기 확인 |
| `/res select vert` | 선택 영역을 위아래로 확장 |
| `/res create 우리집` | 선택한 땅 보호하기 |
| `/res info` | 현재 땅의 소유자와 권한 확인 |
| `/res list` | 내가 보호한 땅 목록 |

## 🔎 블록 기록 조사 — CoreProtect

마루에서는 **일반 유저도** 블록 기록을 조사할 수 있어요.

1. 채팅에 `/co i`를 입력해 조사 모드를 켭니다.
2. 확인하려는 블록을 클릭합니다.
3. 누가 언제 변경했는지 표시된 기록을 확인합니다.
4. 조사가 끝나면 **`/co i`를 다시 입력**해 해제합니다.

```text
/co i
```

:::info
로그 조회는 모든 유저가 할 수 있지만, 복구·롤백 등 관리자 명령어는 일반 유저용 기능이 아닙니다.
:::

[🔎 CoreProtect 상세 안내](/guide/systems/coreprotect)

## 🧑‍🌾 주민 관리 — ClickVillagers

주민 관리는 주로 **명령어 대신 아이템과 마우스 조작**으로 이용합니다.

- **삽 + Shift + 우클릭**: 소유권 등록·관리 메뉴 열기
- **가위 + Shift + 우클릭**: 주민 고정
- **빈손 + Shift + 우클릭**: 주민 줍기
- 거래 리셋: 마루에서는 **일반 유저도 사용 가능**
