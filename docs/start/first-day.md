# 🌱 첫날 생존 가이드

마루에 처음 접속했다면 **장비 준비 → 먹을거리 확보 → 다이아몬드 채굴 → 돈 벌기 → 집터 고르기 → 땅 보호 → 집 짓기** 순서로 시작해 보세요.

## 🗺️ 처음 시작하는 순서

| 단계 | 해야 할 일 | 가이드 |
|---|---|---|
| **1. 🎁 장비 챙기기** | 지급받은 분홍 초심자 방어구를 입고 도구·빵·낚싯대를 챙겨요. | [초심자 세트](./starter.md) |
| **2. 🌳 생존 준비** | 나무, 돌, 석탄, 철을 얻고 제작대와 화로를 만들어요. | 이 페이지 아래 |
| **3. 🍲 음식 마련하기** | 빵으로 시작해 물고기를 잡거나 작물을 재배하고, 제작대에서 음식을 요리해 먹어요. | [마루 요리](../content/cooking.md) |
| **4. 💎 다이아몬드 찾기** | 철 장비와 횃불, 음식을 준비하고 깊은 동굴에서 다이아몬드를 찾아요. | 아래 채굴 팁 |
| **5. 💰 돈 벌기** | 채굴·제작·낚시·이동 보상을 모으고, 거래소에서도 경제 활동을 시작해요. | [활동 보상 금액표](../content/activity-rewards.md) |
| **6. 🏞️ 집터 찾기** | 평탄한 땅과 농사·광산 접근성을 살펴 원하는 위치를 정해요. | 아래 집터 팁 |
| **7. 🛡️ 내 땅 보호하기** | 집을 짓기 전에 Residence로 땅을 먼저 보호해요. | [레지던스 가이드](../systems/residence.md) |
| **8. 🏡 집 짓고 홈 저장** | 집과 상자를 놓고 `/sethome 우리집`으로 귀환 위치를 저장해요. | [이동·홈 명령어](../help/commands.md) |

## 1. 🎁 초심자 장비와 임시 거처

처음 받은 방어구를 착용하고 빵 64개와 낚싯대를 확인하세요. **첫날에는 멀리 탐험하기 전에 나무를 모아 제작대를 만들고, 밤을 보낼 수 있는 임시 공간**부터 준비하면 좋아요.

:::tip 친구에게 이동하고 싶다면
`/tpa 친구닉네임`으로 이동을 요청하고, 상대방은 `/tpaccept`로 수락할 수 있어요.
:::

## 2. 🥗 먹을거리 준비하고 직접 요리하기

마루에는 **낚시(PyroFishingPro)**, **농사(CustomCrops)**, **제작대 요리**가 서로 연결되어 있어요.

1. [낚시 가이드](../content/fishing.md)를 참고해 커스텀 물고기를 잡거나 [농사 가이드](../content/farming.md)에서 작물 재배 방법을 배워요.
2. 채팅에 **`/요리`** 또는 **`/요리책`**을 입력해 원하는 음식의 재료를 확인하세요.
3. 일반 **3×3 제작대**를 열고 필요한 재료를 각각 다른 칸에 배치하세요. **재료 순서는 자유로워요.**
4. 제작대의 완성 칸에서 음식을 꺼내 먹어요. 일부 음식에는 특별한 버프도 있어요.

:::note 제작대에서 만들어요
**요리책은 레시피 확인용**이고, 실제 음식은 제작대에서 완성합니다. 재료를 한 칸에 여러 개 겹쳐 놓지 말고 필요한 개수만큼 칸을 나누세요. 자세한 레시피는 [마루 요리 50종](../content/cooking.md)에서 볼 수 있어요.
:::

## 3. 💎 다이아몬드 찾아보기

다이아몬드 채굴은 첫 정착 자금을 마련하거나 장비를 강화하기 좋은 장기 목표예요.

- 최소한 **철 곡괭이**, 충분한 음식, 횃불과 여분의 블록을 준비하세요.
- 오버월드의 깊은 지하, 특히 **Y -59 부근**에서 다이아몬드 광석을 찾아보세요. 다만 용암과 깊은 동굴 몬스터를 조심해야 해요.
- 발견한 다이아몬드는 장비 제작에 사용할지, 다른 유저와 거래할지 결정하세요.
- 귀중품을 모았다면 무리하게 계속 채굴하지 말고 안전한 곳에 보관하세요.

## 4. 💰 마루 경제 시작하기

마루에서는 **돌을 캐거나, 제작하고, 낚시하고, 이동하는 평범한 활동만으로도 돈을 받을 수 있어요.** 처음에는 [활동별 보상 금액표](../content/activity-rewards.md)를 확인해 보세요.

- 💎 다이아몬드 광석 채굴: 기본 **0.50원/개**
- 🔩 철 광석 채굴: 기본 **0.10원/개**
- 🎣 낚시: 기본 **0.20원/회**
- 🛠️ 아이템 제작: 기본 **0.05원/개**

**활동 보상은 시간당 최대 100원이며**, 누적 지급액에 따라 감액될 수 있어요. 아래와 같이 거래소에서도 경제 활동을 할 수 있습니다.

1. **`/거래소`**로 유저 거래소를 열어요. (서버에서 `/ah` 별칭을 사용하는 경우에도 같은 거래소가 열립니다.)
2. 필요한 물건과 판매 가격을 비교하세요.
3. 판매할 물건을 골라 거래소의 **판매 등록 화면**에서 거래 조건을 확인하고 등록하세요.
4. 거래가 성사되면 게임 내에서 실제로 받은 **돈이나 교환 아이템**을 확인하세요.

:::important 다이아몬드 = 무조건 현금은 아니에요
마루의 거래소는 아이템을 거래하고 판매할 수 있는 경제 콘텐츠입니다. **다이아몬드의 고정 매입가, 자동 환전, 은행 명령어와 땅 구매 가격**은 현재 위키에서 검증되지 않았으므로 숫자나 명령어를 임의로 안내하지 않았어요. 게임 내 거래소와 잔고 표시를 기준으로 확인하세요.
:::

## 5. 🏞️ 집터 찾기

이제 집을 지을 곳을 골라보세요.

- 집과 밭을 모두 만들 수 있을 정도의 **평탄한 공간**을 찾으세요.
- 숲·물·광산과 너무 멀지 않으면 생활하기 편해요.
- 이미 다른 사람이 보호한 땅과 겹치지 않게 살펴보세요.
- 장차 확장할 집, 농장, 주민 거래 공간까지 생각해서 넉넉하게 정하세요.

## 6. 🛡️ Residence로 먼저 땅 보호하기

**집을 짓기 전에 땅부터 보호하는 것을 추천해요.**

1. 영역 선택 도구로 땅의 **대각선 두 모서리**를 지정하세요.
2. `/res select size`로 선택 크기를 확인하세요.
3. `/res create 우리집`으로 보호 구역을 생성하세요.
4. `/res info`와 `/res show`로 실제 보호 여부를 확인하세요.

서버마다 선택 도구, 면적 한도와 비용이 다를 수 있으므로 반드시 [Residence 전체 사용법](../systems/residence.md)에서 확인하세요.

### 친구와 같이 건축할 때

친구에게 믿을 수 있는 권한을 주려면 `/res pset 친구닉네임 trusted true`를 사용할 수 있어요. 다른 사람에게 너무 넓은 권한을 주지 않도록 주의하세요.

## 7. 🏡 집 완성하고 홈 저장하기

보호한 땅에 집과 상자, 농장, 요리 공간을 만들어요. 완성되면 집 안의 안전한 위치에서 다음을 입력하세요.

```text
/sethome 우리집
/home 우리집
```

기본 홈은 3개까지 저장하도록 구성되어 있어요. [전체 명령어 가이드](../help/commands.md)에서 `/back`, `/spawn`, 친구 이동도 알아보세요.
