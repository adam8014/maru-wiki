# 🌱 첫날 생존 가이드

마루 서버에 처음 도착했다면 다음 순서로 움직여 보세요.

1. 시작 장비를 확인하고 방어구를 착용합니다.
2. 주변에서 나무와 식량을 확보합니다.
3. 안전한 장소에 임시 거처를 만듭니다.
4. 중요한 상자와 건축물을 관리하고 타인과의 분쟁을 예방합니다.
5. [CoreProtect 조사 기능](../systems/coreprotect.md)을 익혀 블록 변경 기록을 확인해 보세요.

:::note 첫 접속 위치
마루에서 신규 유저를 랜덤한 지역에 배치하는 설정을 검토한 이력이 있습니다. 현재 운영 서버에 적용된 좌표 범위는 별도 확인이 필요합니다.
:::
