# 🎮 서버 접속하기

1. **마인크래프트 Java Edition**을 실행합니다.
2. 서버에서 안내한 지원 버전을 선택합니다.
3. **멀티플레이 → 서버 추가**로 이동합니다.
4. 마루 서버에서 공지한 주소를 입력하고 접속합니다.
5. 리소스팩 적용 안내가 표시되면 허용합니다.

:::caution 접속 주소 및 버전
정확한 접속 주소와 호환 버전은 운영자 공지에서 확인해 주세요. 이 문서에는 확인되지 않은 주소를 임의로 적지 않았습니다.
:::
