# 🌸 마루 서버 공식 가이드

**너의 이야기가 피어나는 세계, MARU.**

마루를 처음 찾은 모험가라면 아래 순서대로 시작해 보세요. **장비·음식·채굴·경제·집터·땅 보호**까지 첫 정착 과정을 하나씩 안내합니다.

## 🌱 첫 모험, 이렇게 시작하세요

1. [서버 접속하기](./start/connect.md) — 게임 접속과 리소스팩 허용
2. [마루 초심자 세트](./start/starter.md) — 시작 장비와 식량 확인
3. [리소스팩 적용하기](./start/resources.md) — 커스텀 물고기와 요리 이미지 표시
4. [첫날 생존 가이드](./start/first-day.md) — **생존부터 첫 집 보호까지 전체 순서**
5. [낚시 입문](./content/fishing.md) / [농사 시작](./content/farming.md) — 음식 재료 구하기
6. [마루 요리 50종](./content/cooking.md) — 요리책 확인 후 제작대에서 만들어 먹기
7. [활동 보상으로 돈 벌기](./content/activity-rewards.md) — 채굴·제작·낚시·이동으로 돈을 모으고 거래소도 이용하기
8. [Residence 땅 보호](./systems/residence.md) — 집터를 고른 뒤 보호 영역 만들기
9. [유저 명령어](./help/commands.md) — `/sethome`, `/home`, `/tpa` 등 이용하기

## 🏡 목표는 나만의 안전한 첫 집!

**다이아몬드를 모으고 → 요리해서 체력을 챙기고 → 경제 활동을 시작하고 → 집터에 보호를 걸고 → 나만의 마루 생활을 시작하세요.**

:::info 문서 업데이트 안내
경제·보호구역의 비용이나 잔고 명령어는 서버의 실제 설정에 따라 다를 수 있습니다. 아직 확인하지 못한 구체적인 금액은 임의로 적지 않았어요.
:::
