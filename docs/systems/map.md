# 🗺️ 마루 미니맵과 정보 HUD

마루 서버에서는 클라이언트 모드를 따로 설치하지 않아도 **서버 리소스팩으로 표시되는 미니맵**을 이용할 수 있어요. 지도와 정보창을 각각 켜거나 끌 수 있고, 화면 위치도 변경할 수 있습니다.

## ✨ 주요 기능

- **미니맵**: 현재 주변의 지형과 위치를 작은 지도로 표시
- **좌표**: 현재 X·Y·Z 좌표 확인
- **계절**: CustomCrops의 현재 계절 표시
- **시간**: 게임 속 시간 확인
- **기타 정보**: 서버에서 제공하는 바이옴·통장 등 HUD 정보
- **화면 위치 변경**: 왼쪽 또는 오른쪽에 배치
- **개인 설정 저장**: 위치와 표시 설정은 재접속해도 유지

정보창은 **좌표 → 계절 → 시간** 순서로 표시되며, 나머지 정보도 서버 HUD에 함께 나타날 수 있어요.

## ⌨️ 명령어

| 명령어 | 기능 |
|---|---|
| `/미니맵` | 미니맵 켜기·끄기 전환 |
| `/미니맵 켜기` | 미니맵 지도 켜기 |
| `/미니맵 끄기` | 미니맵 지도 끄기 |
| `/미니맵 왼쪽` | 지도와 정보창을 왼쪽으로 이동 |
| `/미니맵 오른쪽` | 지도와 정보창을 오른쪽으로 이동 |
| `/미니맵 정보` | 정보창 표시 전환 |
| `/미니맵 정보 켜기` | 좌표·계절·시간 등의 정보창 표시 |
| `/미니맵 정보 끄기` | 정보창 숨기기 |
| `/미니맵 도움말` | 게임 안에서 명령어 도움말 보기 |

**참고:** `/미니맵 좌측`, `/미니맵 우측`, `/미니맵 on`, `/미니맵 off`, `/미니맵 정보창`, `/미니맵 좌표` 같은 별칭도 지원합니다.

## 🎨 모드·셰이더 사용 중 지도가 깨져 보인다면?

일부 클라이언트 모드 또는 셰이더와 마루 리소스팩의 지도 표시 방식이 충돌해 **지도가 이상하게 보이거나 화면 표시가 깨지는 현상**이 확인됐어요.

이럴 때는 다음 순서로 해결해 보세요.

1. 채팅창에 **`/미니맵 끄기`**를 입력합니다.
2. 미니맵 지도가 사라진 뒤 화면 표시가 정상으로 돌아오는지 확인합니다.
3. 지도만 끈 상태에서도 **좌표·계절·시간 정보창은 계속 사용할 수 있어요.**
4. 정보창까지 겹치거나 깨진다면 **`/미니맵 정보 끄기`**를 추가로 입력합니다.
5. 셰이더나 충돌하는 모드를 끈 뒤 **`/미니맵 켜기`**로 지도를 다시 사용할 수 있습니다.

### 추천 설정

| 상황 | 추천 명령어 |
|---|---|
| 셰이더를 사용하는데 지도만 깨짐 | `/미니맵 끄기` |
| 지도는 끄고 좌표와 계절만 보고 싶음 | `/미니맵 끄기` + `/미니맵 정보 켜기` |
| 정보창만 깨짐 | `/미니맵 정보 끄기` |
| HUD가 다른 모드 화면과 겹침 | `/미니맵 왼쪽` 또는 `/미니맵 오른쪽` |
| 원래대로 미니맵 다시 사용 | `/미니맵 켜기` + `/미니맵 정보 켜기` |

:::tip 설정은 저장됩니다
미니맵 표시, 정보창 표시, 좌우 위치는 **플레이어별로 저장**되므로 게임에 다시 접속해도 이전 설정이 유지돼요.
:::

:::warning 셰이더나 모드를 삭제할 필요는 없어요
문제가 생기면 먼저 `/미니맵 끄기`를 시도하세요. 이것은 서버의 미니맵 HUD만 숨기는 기능으로, 월드나 인벤토리에는 영향을 주지 않습니다. 특정 모드·셰이더의 모든 충돌이 해결된다는 뜻은 아닙니다.
:::

## ❓ 자주 묻는 질문

**Q. 셰이더를 쓰는데 지도 표시가 이상해요.**  
`/미니맵 끄기`로 지도를 숨겨 보세요. 다른 표시가 정상이라면 지도만 끄고 게임을 계속 즐길 수 있어요.

**Q. 미니맵은 싫지만 좌표·계절·시간은 보고 싶어요.**  
`/미니맵 끄기`와 `/미니맵 정보 켜기`를 입력하면 됩니다.

**Q. 정보가 왼쪽에 있어서 다른 모드 HUD와 겹쳐요.**  
`/미니맵 오른쪽`으로 위치를 바꾸세요.

**Q. 로그아웃했다 들어오면 다시 켜지나요?**  
아니요. 개인별 표시 설정과 위치가 저장됩니다.

**Q. 일부 구버전 클라이언트에서 보이지 않아요.**  
서버의 리소스팩·클라이언트 버전 호환 조건에 따라 지도가 표시되지 않을 수 있습니다. 서버에서 안내하는 지원 버전으로 접속해 주세요.
