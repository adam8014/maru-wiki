# 🔎 CoreProtect — 누가 건드렸을까?

마루 서버에서는 **일반 유저도 `/co i` 명령어로 블록 변경 기록을 조회**할 수 있도록 운영하고 있습니다.

## 사용 방법

1. 채팅창에 `/co i`를 입력해 조사 모드를 켭니다.
2. 조사하고 싶은 블록을 클릭해 표시되는 기록을 확인합니다.
3. 조사가 끝나면 `/co i`를 다시 입력해 조사 모드를 해제합니다.

**예시**

```text
/co i
```

:::tip
상자나 블록의 기록을 확인할 때는 게임 내 채팅에 표시되는 기록을 참고하세요. 의심스러운 피해가 있으면 좌표와 시간을 함께 운영진에게 알려주세요.
:::

:::caution 권한 안내
일반 유저는 조회 용도로 사용합니다. 롤백 등 복구 명령은 운영자 권한이며, 이 문서에서 일반 유저에게 제공한다고 안내하지 않습니다.
:::
