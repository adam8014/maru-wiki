# 🎒 마루 개인 가방과 창고

마루에서는 **Shift+F**를 눌러 언제든 개인 창고를 열 수 있어요. 창고는 들고 다니는 아이템이 아니라 **계정별로 저장되는 가상 공간**입니다. **최대 5개, 각 54칸으로 총 270칸**을 사용할 수 있어요.

## ⌨️ 여는 방법

| 조작 | 기능 |
|---|---|
| **Shift+F** | 개인 가방 메뉴 열기 |
| `/가방` | 개인 가방 메뉴 열기 |
| `/창고` | 개인 가방 메뉴 열기 |
| `/가방제작법` | 단계별 추가권 조합법 |
| `/창고제작법` | 위 명령어의 별칭 |

**신규 유저에게는 초심자 장비와 함께 1번 창고 추가권 한 장이 지급됩니다.** 기존 유저에게는 자동 소급 지급되지 않아요.

### 추가권 사용하는 순서

1. 1번 창고 추가권을 **주 손에 들고 우클릭**해 첫 창고를 해금합니다.
2. **Shift+F**로 개인 창고 메뉴를 엽니다.
3. **1번 창고**를 클릭하여 54칸 보관함을 이용합니다.
4. 2번부터 5번까지는 아래 레시피로 추가권을 제작하고, **순서대로 해금**합니다.
5. 이미 연 단계나 잘못된 단계의 추가권은 소모되지 않습니다.

## 🛠️ 3×3 제작대 추가권 조합법

**각 줄은 제작대의 윗줄·가운데 줄·아랫줄**입니다. 아래 재료를 **해당 위치에 맞춰** 넣어 주세요.

### 1번 창고 — 가죽 가방

```text
가죽 | 가죽 | 가죽
가죽 |  실  | 가죽
가죽 | 가죽 | 가죽
```

**가죽 8개 + 실 1개**

### 2번 창고 — 철제 가방

```text
가죽 | 철 주괴 | 가죽
철   |  상자   | 철
가죽 | 철 주괴 | 가죽
```

**가죽 4개 + 철 주괴 4개 + 상자 1개**

### 3번 창고 — 황금 가방

```text
금 주괴  | 다이아몬드 | 금 주괴
다이아  |  엔더 상자  | 다이아
금 주괴  | 다이아몬드 | 금 주괴
```

**금 주괴 4개 + 다이아몬드 4개 + 엔더 상자 1개**

### 4번 창고 — 네더 가방

```text
다이아블록 | 네더라이트 파편 | 다이아블록
네더파편   |    엔더 상자    | 네더파편
다이아블록 | 네더라이트 파편 | 다이아블록
```

**다이아몬드 블록 4개 + 네더라이트 파편 4개 + 엔더 상자 1개**

### 5번 창고 — 최고급 가방

```text
네더라이트 주괴 | 네더의 별 | 네더라이트 주괴
다이아몬드 블록 | 엔더 상자 | 다이아몬드 블록
네더라이트 주괴 |   신호기  | 네더라이트 주괴
```

**네더라이트 주괴 4개 + 다이아몬드 블록 2개 + 네더의 별 1개 + 엔더 상자 1개 + 신호기 1개**

:::tip 제작 팁
**일반 제작대 3×3 칸**에서 위 모양 그대로 제작해야 합니다. 이름·설명이 변경된 특수 재료는 추가권 제작에 사용할 수 없을 수 있습니다.
:::

## 📦 아이템 자동 수납

일반 인벤토리가 **완전히 꽉 차서 바닥의 아이템을 더 주울 수 없을 때**, 해금된 개인 창고로 자동 수납됩니다.

- 1번 창고부터 차례대로 빈 공간을 찾습니다.
- 인벤토리에 일부라도 빈 자리가 있으면 일반적인 아이템 줍기가 먼저 적용됩니다.
- 창고까지 가득 찼다면 남은 아이템은 **바닥에 그대로 남습니다.**
- 다른 플레이어 소유의 아이템이나 보호 플러그인이 줍기를 거절한 아이템은 가져오지 않습니다.
- 채굴·낚시 보상을 다른 플러그인이 **직접 인벤토리에 지급하는 경우**는 자동 수납 대상이 아닙니다.

## ⚔️ 사망과 미니게임

- **사망해도 개인 창고의 아이템은 유지됩니다.** 일반 인벤토리의 아이템은 서버의 사망 상자 규칙을 따릅니다.
- **CS어택 참가·관전 중**, 또는 `maru_`로 시작하는 미니게임 월드에서는 창고 열기와 자동 수납이 제한됩니다.
- 평상시의 **F키 보조 손 교체**는 유지되고, **Shift+F**만 가방 단축키로 사용됩니다.
- 개인 창고는 계정별로 저장되므로 재접속 후에도 사용할 수 있습니다.
