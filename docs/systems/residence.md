# 🏡 Residence — 내 땅 보호하기

집이나 농장을 만들었다면 **Residence(레지던스)**로 영역을 보호하세요. 다른 사람이 내 건축물을 부수거나 상자를 여는 것을 제한하고, 친구에게만 권한을 줄 수 있습니다.

## 🌱 처음 5분: 내 땅 보호하기

1. 보호할 집이나 농장의 **서로 마주 보는 두 모서리**를 찾습니다. 높이까지 포함한 직육면체를 선택한다고 생각하면 쉬워요.
2. **영역 선택 도구**로 첫 번째 모서리를 좌클릭, 반대쪽 모서리를 우클릭하세요.
3. `/res select size`로 크기를 확인합니다.
4. `/res select vert`로 선택 영역을 위아래로 확장할 수 있습니다(서버 설정에 따라 허용 범위가 다릅니다).
5. `/res create 우리집`을 입력해 보호 구역을 만듭니다.
6. `/res show` 또는 `/res info`로 생성된 보호 영역을 확인하세요.

:::important 선택 도구는 서버마다 다를 수 있어요
Residence의 선택 도구는 설정에서 바꿀 수 있습니다. 일부 버전은 **나무 도끼**를 사용하고, 다른 설정은 괭이 등 다른 도구를 씁니다. 마루 서버의 정확한 선택 도구는 아직 확인되지 않았으므로, 게임에서 `/res ?` 안내를 먼저 확인하세요.
:::

### 📐 선택 영역을 이해하는 그림

```text
        ② 반대편 위쪽 모서리
       ╱│
      ╱ │        ← 집과 농장을 포함할 공간
     ╱  │
    ┌───────────┐
    │  내 집 🏠  │
    │  내 밭 🌱  │
    └───────────┘
   ① 첫 번째 모서리
```

**너무 작게 지정하면 지붕·지하실이 보호되지 않을 수 있어요.** 실제 보호 범위는 `/res show`에서 확인하세요.

## 🧰 자주 쓰는 명령어

| 명령어 | 무엇을 할까요? |
|---|---|
| `/res ?` | 레지던스 명령어 도움말 |
| `/res create 우리집` | 선택한 영역을 '우리집'으로 보호 |
| `/res select size` | 선택한 영역 크기 확인 |
| `/res select vert` | 선택 영역을 위아래로 확장 |
| `/res select chunk` | 현재 청크를 선택 |
| `/res current` | 현재 서 있는 보호구역 이름 확인 |
| `/res info` | 보호구역 정보와 권한 확인 |
| `/res list` | 내가 보유한 보호구역 목록 |
| `/res limits` | 내 보호 가능 크기·개수 제한 확인 |
| `/res show` | 보호 영역 테두리 표시 |
| `/res remove 우리집` | '우리집' 보호구역 삭제 요청 |
| `/res confirm` | 삭제 등 확인이 필요한 작업 승인 |

## 👥 친구에게 건축 권한 주기

내 땅 안에 서서 다음 명령어를 입력합니다.

```text
/res pset 친구닉네임 trusted true
```

**trusted**는 여러 권한을 묶은 설정입니다. 친구가 건축·상자 사용·이동 등 광범위한 작업을 할 수 있으니 믿을 수 있는 사람에게만 부여하세요.

권한을 취소하려면:

```text
/res pset 친구닉네임 trusted false
```

### 필요한 권한만 개별 허용하기

| 명령어 | 친구에게 허용하는 것 |
|---|---|
| `/res pset 친구닉네임 build true` | 건축·블록 변경 |
| `/res pset 친구닉네임 container true` | 상자 등 보관함 사용 |
| `/res pset 친구닉네임 use true` | 버튼 등 상호작용 |
| `/res pset 친구닉네임 move true` | 보호 영역 출입·이동 허용 |

위 명령어의 `true`를 `false`로 바꾸면 해당 권한을 제한할 수 있어요. **`remove`**는 지정값을 제거하고 상위·기본 설정으로 되돌리는 방식이므로, 항상 차단을 의미하지는 않습니다.

## ⚙️ 내 땅 전체의 규칙 설정

`/res set`은 영역 전체에 적용할 규칙을 변경합니다.

| 예시 | 설명 |
|---|---|
| `/res set pvp false` | 보호 구역 안에서 PvP 제한 |
| `/res set container false` | 일반 방문객의 상자 사용 제한 |
| `/res set use false` | 일반 방문객의 버튼 등 사용 제한 |
| `/res set tnt false` | TNT 관련 피해 제한 |
| `/res set creeper false` | 크리퍼 폭발 관련 제한 |

:::warning
서버에서 허용한 플래그만 변경할 수 있어요. **마루 서버의 실제 권한·가격·면적 한도·폭발 정책은 플러그인 설정에 따라 달라집니다.** `/res limits`와 게임 내 메뉴에 표시된 값을 우선하세요.
:::

## 🗑️ 땅 보호 해제하기

1. `/res remove 우리집` 입력
2. 삭제 확인 메시지가 뜨면 `/res confirm` 입력
3. `/res list`로 보호구역이 없어졌는지 확인

:::caution
보호를 해제한 땅은 더 이상 기존 보호 규칙이 적용되지 않을 수 있어요. 실수로 삭제하지 않도록 이름을 다시 확인하세요.
:::

## ❓ 자주 묻는 질문

**Q. 땅이 너무 작다고 나와요.**  
서버의 최소·최대 면적 조건과 가격 설정을 확인하세요. `/res limits`에서 한도를 볼 수 있습니다.

**Q. 다른 사람 땅과 겹쳐요.**  
이미 등록된 보호 영역과 겹치면 새 영역이 만들어지지 않을 수 있습니다. 모서리를 다시 선택하세요.

**Q. 친구가 내 집 문은 열지만 상자를 못 열어요.**  
`container` 권한을 별도로 확인하고 필요한 경우 친구에게만 허용하세요.

**Q. 도끼나 괭이로 모서리를 클릭해도 아무것도 안 나와요.**  
서버가 지정한 선택 도구인지 확인하세요. `/res ?`의 도움말이나 서버 안내에 따라 선택 도구를 확인하는 게 가장 정확합니다.
